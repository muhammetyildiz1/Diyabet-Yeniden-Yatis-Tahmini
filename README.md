# Makine Öğrenmesi Haftalık Çalışmaları

Bu repo, Makine Öğrenmesi dersi kapsamında gerçekleştirdiğimiz haftalık çalışmaları, ödevleri ve proje kodlarını içermektedir. Her haftanın çalışması kendi klasörü içerisinde yer almaktadır.

## Çalışma Ekibi

* Muhammet Yıldız
